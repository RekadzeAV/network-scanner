# Блокер: Зацикливание на повышении покрытия internal/scanner (TASK-v2.3.0-M1.1)

**Дата:** 2026-09-08  
**Блокер ID:** BLOCKER-003  
**Статус:** ⚠️ Требует решения

## Описание

При реализации М1.1 (тесты для `internal/scanner`, 72.0% → 85%+) AI-ассистент зациклился на повторном запуске `go test ./internal/scanner` без анализа покрытия.

## Хронология

| Попытка | Действие | Результат |
|---------|----------|-----------|
| 1 | `go test ./internal/scanner -count=1 -coverprofile=scanner_cov_v3.out` | 73.5% (+1.5%), 95 сек |
| 2 | Повторный запуск той же команды | 73.5% (кэшировано), 95 сек |
| 3 | Повторный запуск без изменений | **Зацикливание обнаружено** |

## Причина

1. **Долгие тесты:** полные тесты scanner занимают ~95 секунд
2. **Отсутствие анализа:** запуск тестов без `go tool cover -func` для выявления непокрытых функций
3. **Петля "запуск → 73.5% → повторный запуск":** без анализа причин и написания новых тестов

## Текущее состояние

- Coverage: 73.5% (было 72.0%, +1.5% после добавления 14 тестов)
- Цель: 85%
- Прогресс: +1.5% из ~13% необходимых
- Добавлено тестов: 14 (TestReadMACFromLinuxARP_*, TestReadMACFromDarwinARP_*, TestSet*)

## Возможные решения

### Вариант 1: Анализ `go tool cover -func`
```bash
# Правильный порядок:
go test ./internal/scanner -count=1 -coverprofile=scanner_cov.out
go tool cover -func=scanner_cov.out | Select-String "0.0%|< 50%"
# Написать тесты для непокрытых функций
```

### Вариант 2: Фокус на низко-покрытых функциях
- Найти функции с 0-30% покрытием
- Написать targeted тесты именно для них
- Избегать тестов для функций с >80% покрытием

### Вариант 3: Переключение на другие пакеты
- `internal/network` (77.7% → 85%)
- `internal/topology` (78.4% → 85%)
- Scanner имеет plateau на 73.5%, возможно требует архитектурных изменений

## Выводы

- Долгие тесты (>90 сек) затрудняют итеративную разработку
- Необходимо использовать `go tool cover -func` ДО написания тестов
- При plateau на 1-2% после добавления тестов — переключиться на другие пакеты

## Статус

⚠️ Требуется решение: Вариант 1 (анализ) или Вариант 3 (переключение)
