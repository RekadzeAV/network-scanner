# GUI Smoke-чеклист (ручные проверки)

Документ содержит пункты приёмки дизайна GUI, которые **невозможно** автоматизировать
и требуют визуальной проверки на живом приложении.

## Автоматизированные проверки

Автоматизированные пункты (§13, ссылки `scripts/check-gui.ps1`) проверяются командой:

```powershell
# Полный прогон (~1–3 мин, с тестами)
.\scripts\check-gui.ps1

# Быстрый прогон (без тестов, ~5 сек)
.\scripts\check-gui.ps1 -SkipTests
```

Полный список автоматизированных пунктов — в
[docs/GUI_DESIGN_RECOMMENDATIONS.md §13](GUI_DESIGN_RECOMMENDATIONS.md#13-чеклист-приёмки-дизайн-изменений-для-pr).

## Как запустить GUI

GUI-приложение собирается из корня репозитория:

```powershell
# Сборка
go build -o network-scanner-gui.exe ./cmd/gui

# Запуск
.\network-scanner-gui.exe
```

или, если уже собран бинарник в корне:

```powershell
.\network-scanner-gui.exe
```

> Подсказка: скрипт `scripts/smoke-gui-resolution.ps1` помогает загрузить GUI
> для ручного прогона матрицы разрешений.

## Чекбоксы (ручная проверка)

> Каждый пункт — строка, которую нужно проверить на запущенном GUI.
> Отмечайте выполнение вручную или копируйте в PR.

- [ ] **Меню «Тема»**: три режима (light / dark / system) переключаются,
      активный режим отмечен, порядок акцентных цветов стабилен при перезапуске.

- [ ] **FYNE_SCALE**: в коде не устанавливается (`grep -rn FYNE_SCALE internal/gui`);
      прогон GUI на 100 % / 125 % / 150 % — элементы не вылазят за границы.

- [ ] **Вкладка «Результаты»**: live-строки появляются во время скана;
      заголовок таблицы остаётся видимым при скролле; сортировка по клику по заголовку
      колонки работает и сохраняется между вкладками.

- [ ] **Статус-бар**: виден на всех вкладках; сообщения об ошибках визуально
      отличаются от сообщений об успехах (цвет / иконка).

- [ ] **Пустые / ошибочные состояния**: содержат призыв к действию (кнопка, ссылка,
      подсказка) — не «мёртвый экран».

- [ ] **Форматирование адресов**: MAC-, IP-, портовые значения отображаются моноширинным
      шрифтом; длинные значения усечены многоточием без битых символов.

- [ ] **Состояние порта**: различимо не только цветом, но и формой/иконкой/текстом
      (WCAG 1.4.1 — информация не только цветом).

- [ ] **Интерактивная карта топологии**: курсор меняется над узлами и рёбрами;
      hit-радиус ≥ 12 px; цвета элементов взяты из токенов (не хардкод).

- [ ] **Скриншоты к PR**: приложены скриншоты light- и dark-тем «до» и «после»
      дизайн-правок.
