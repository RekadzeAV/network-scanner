# GUI Smoke-чеклист (ручная проверка GUI-режимов)

Назначение: быстрая ручная regression-проверка GUI перед релизом.
Все проверки выполняются на dev-сборке (`go build -tags gui ./cmd/network-scanner-gui`).

## 1. Запуск и базовый режим
- [ ] GUI стартует без ошибок, окно появляется за разумное время
- [ ] Заголовок и иконка корректны
- [ ] Пустое состояние: подсказка о запуске сканирования видна

## 2. Сканирование
- [ ] Целевой ввод `127.0.0.1/32`, короткий диапазон портов (1-10)
- [ ] Прогресс-бар обновляется, кнопки отмены активны
- [ ] Результаты: таблица хостов/портов заполняется, форматированный вывод толерантен к сырым banner
- [ ] Флаг `--show-raw-banners` (если доступен из GUI) переключает banner-секцию

## 3. Топология
- [ ] SNMP summary секция появляется при включенном topology-режиме
- [ ] Экспорт topology: json/graphml кнопки создают файлы
- [ ] PNG-экспорт: fallback-режим без Graphviz не роняет GUI

## 4. Инструменты (ping/dns)
- [ ] `ping 127.0.0.1` выводит секцию raw
- [ ] `dns localhost` резолвится, секция raw присутствует
- [ ] Негативные кейсы (невалидный хост) показывают понятную ошибку, не краш

## 5. Отчёты и аудит
- [ ] Security report генерируется, секции `CVE Findings` и `Risk Signature Findings` присутствуют
- [ ] Audit view: фильтр по severity работает, fallback при невалидном значении
- [ ] Device-control negative-case: невалидный MAC отклоняется с ошибкой

## 6. Настройки и навигация
- [ ] Все вкладки открываются, переключение без артефактов
- [ ] Настройки сохраняются между сессиями
- [ ] Диалоги ошибок не блокируют главное окно

## 7. Адаптивность (автоматически)
```bash
# Linux/macOS
./scripts/smoke_release_readiness.sh ./network-scanner-gui
```
```powershell
# Windows PowerShell
.\scripts\smoke_release_readiness.ps1 -GuiExe .\network-scanner-gui.exe
```
- [ ] Типовые разрешения (1366x768, 1920x1080) и DPI (100%, 150%) проходят без обрезки контента

## Формат фиксации
При обнаружении regression — issue с шагами, скриншотом и выводом GUI-логов.
Чеклист считается пройденным при 100% отмеченных пунктов.
