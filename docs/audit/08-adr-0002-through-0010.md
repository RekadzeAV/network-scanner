## ADR-0002 — Архитектурный слой v2.3 (plugin/eventbus/commands/apperror/configvalidation)

**Статус:** ✅ Принято (E6, 2026-09-19)  
**Контекст:** Слои plugin, eventbus, commands, apperror, configvalidation созданы с тестами, но не подключены к приложениям (0 импортов вне своих пакетов).  
**Решение:**  
- НЕ ретрофитить apperror в легаси-бизнес-пути (высокий риск регрессий без пользовательской ценности).  
- Слой остаётся протестированным фундаментом: новые фичи пишутся на apperror/eventbus/commands с первого коммита.  
- internal/plugin (60%) — добирать покрытие при появлении реальных плагинов.  

**Негативные последствия:** Запасные пакеты остаются неинтегрированными до появления реального спроса.

## ADR-0003 — TCP-probe (scanner)

**Статус:** ✅ Принято  
**Контекст:** Сканер использует TCP-подключение для проверки портов.  
**Решение:**  
- TCP-подключение с таймаутом (настраиваемый `--timeout`).  
- Параллельные воркеры (`--threads`).  
- Отображение статуса (open/filtered/closed).  

**Покрытие:** 84.7%

## ADR-0005 — SQLite как хранилище инвентаря

## ADR-0008 — Safety guards (confirm + allowlist)

**Статус:** ✅ Принято  
**Контекст:** Операции device-control и remote-exec потенциально опасны.  
**Решение:**  
- **Confirm по умолчанию** для device-control (изменение настроек устройств).  
- **Allowlist** для remote-exec (разрешённые команды).  
- **Dry-run по умолчанию** для remote-exec (`--no-dry-run` для реального выполнения).  

**Риски:** `[RISK]` remote-exec без dry-run, device-control без confirm по умолчанию — `[TODO]` P0.

## ADR-0009 — CLI framework (cobra)

**Статус:** ✅ Интегрировано (2026-09-19)  
**Контекст:** `spf13/cobra` как indirect dependency; `cmd/network-scanner/cmd/scan_cobra.go` не подключён.  
**Решение:**  
- `main → ExecuteCLI (scan.go) → scanCmd.RunE (scan_cobra.go)` — использует реальную бизнес-логику (scanner/snmpcollector/builder/display/presenter).  
- Cobra живой, подключён к основному CLI.  

**Комментарий:** cmd/network-scanner/cmd без юнит-тестов — допустимо, сценарный путь CLI покрыт e2e-сканами scanner.
